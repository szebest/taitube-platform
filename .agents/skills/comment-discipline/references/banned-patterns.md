# The pattern catalogue

`SKILL.md` has the short table. This is the full list, usable as a review checklist or as
the rule set of a hook or lint.

## Banned

| Reason | Shape |
| --- | --- |
| refers to the conversation | `as the user requested`, `as agreed`, `as discussed`, `per the prompt` |
| refers to the review | `per review`, `per the reviewer`, `addressed PR comments` |
| cites requirements or a plan | `AC-3`, `acceptance criteria`, `step 2 of the plan`, `phase 1 of the migration` |
| an internal doc or ticket as the explanation | `see PLAN.md`, `implements the design doc`, `see ABC-123`, `Fixes ABC-42`, a bare `ABC-123` |
| narrates the diff | `switched from X to Y`, `refactored`, `rewrote`, `reverted`, `now also handles`, `we no longer`, `this PR`, `this commit` |
| a version nobody will see | `formerly`, `used to be`, `no longer needed`, `before this change`, `instead of the old` |
| justifies why code was added | `added this because the ticket ...` |
| commented-out code | a body that parses as a statement |
| banner or divider | `// ------`, `// ===== SELECTORS =====` |
| emoji | any emoji |
| non-actionable TODO | `TODO: as discussed`, `TODO: see ...` |
| mentions the assistant | `AI-generated`, `generated by <tool>` |
| narrates reasoning | `First we ...`, `Then I ...` |

## Suspect: delete unless you can name the wrong change it prevents

| Reason | Shape |
| --- | --- |
| restates the next line | opens with `increments`, `returns`, `sets`, `loops over`, `checks if`, `handles` |
| restates the declaration | `this function is ...`, `the component handles ...` |
| filler opener | `note that`, `important:`, `obviously`, `simply`, `just` |
| restates that a helper is a helper | `helper function`, `utility`, `convenience wrapper` |
| unfalsifiable | `for readability`, `for clarity`, `for consistency` |
| says nothing | `self-explanatory`, `straightforward` |
| a test label | `Arrange`, `Act`, `Assert`, `Given`, `When`, `Then`, `setup` |
| restates the assertion | `should ...`, `verifies that ...` |
| reads as diff narration | opens with `moved`, `changed`, `renamed`, `extracted`, `replaced`, `removed`; contains `previously`, `old implementation` |
| a bare label | only `workaround`, `hack`, `temp`, `defaults`, `types`, `handlers` |
| no end date | `for now`, `temporary`, `placeholder` |

## Never touched

Suppressions and pragmas (`eslint-disable`, `biome-ignore`, `@ts-expect-error`,
`prettier-ignore`, `# noqa`, `# type: ignore`, `nolint`), build directives (`//go:generate`,
shebangs, `/* global */`), generated-file and licence headers (`@generated`, SPDX,
copyright), coverage directives (`istanbul ignore`, `c8 ignore`) and `@deprecated use X`
pointers. They are exempt from the budget and from judgement calls, not from the banned
table: a directive whose reason says "as discussed" is still banned.

Public identifiers (`CVE-`, `RFC`, `GHSA-`, `WCAG`, an upstream issue URL) are evidence,
not ticket references.

## Prose that reads banned but is not

A present-tense description that happens to use a narration word is fine:

```ts
// Removed entries keep their id so undo can restore them.
// Rate limit is 100 requests per user, per minute.
// The trailing slash is part of the OAuth redirect; do not strip it.
```
